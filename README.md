## 🏆 Destaque: PlayWithEliteItem — Risk of Rain 2

**Meu mod publicado na comunidade de Risk of Rain 2.** Ao iniciar uma partida, os jogadores recebem um equipamento de elite aleatório, trazendo variedade para cada run.

| Publicação | Informações |
| --- | --- |
| **Onde jogar/instalar** | [Thunderstore — PlayWithEliteItem](https://thunderstore.io/c/riskofrain2/p/CONDE/PlayWithEliteItem/) |
| **Alcance** | **Aproximadamente 4 mil downloads** no Thunderstore (referência: outubro de 2026) |
| **Versão publicada** | **1.0.1** |
| **Código-fonte** | [GitHub — PlayWithEliteItem](https://github.com/HelioConde/PlayWithEliteItem) |
| **Tecnologias** | **C# · BepInEx · .NET · APIs de Risk of Rain 2** |

O projeto representa minha experiência com **lógica de jogo, integração com APIs de jogos, multiplayer, plugins e distribuição para jogadores reais**.

> **Transparência:** o GitHub documenta uma refatoração **1.1.0 em testes**. Ela ainda **não** é a versão disponível no Thunderstore.

[**🎮 Ver o mod no Thunderstore**](https://thunderstore.io/c/riskofrain2/p/CONDE/PlayWithEliteItem/) · [**💻 Explorar o código**](https://github.com/HelioConde/PlayWithEliteItem)
