## ⭐ Projetos que representam meu trabalho

### 🎮 01 · PlayWithEliteItem — mod publicado para Risk of Rain 2

**Um projeto que chegou à comunidade do jogo.** O mod distribui equipamentos de elite aleatórios no começo das partidas, adicionando variedade à experiência.

- **Publicação:** [Thunderstore — CONDE / PlayWithEliteItem](https://thunderstore.io/c/riskofrain2/p/CONDE/PlayWithEliteItem/)
- **Alcance:** aproximadamente **4 mil downloads** na publicação (referência de outubro de 2026).
- **Tecnologias:** C#, BepInEx, .NET e integração com as APIs do jogo.
- **Situação:** versão **1.0.1 publicada**; código posterior do GitHub em modernização e testes de compatibilidade.

[**Ver código-fonte e documentação técnica →**](https://github.com/HelioConde/PlayWithEliteItem)

### 🍕 02 · Base Studio Pizzas — plataforma full-stack concluída

**Projeto de portfólio finalizado (v1.0).** Sistema de delivery com cardápio, carrinho, checkout, painel administrativo e área do entregador, incluindo acompanhamento de pedidos e mapas.

![Prévia da interface de Base Studio Pizzas](https://raw.githubusercontent.com/HelioConde/site-pizzaria/main/public/images/hero/hero1.png)

`React 19` · `Vite` · `Supabase` · `PostgreSQL` · `Leaflet` · `Stripe (integração configurável)`

[**🌐 Ver demonstração**](https://helioconde.github.io/site-pizzaria/) · [**📂 Abrir repositório**](https://github.com/HelioConde/site-pizzaria)

<sub>Entrega concluída como projeto de portfólio; a operação comercial depende da configuração e validação dos serviços externos.</sub>

### 🛒 03 · Ofertamática — tecnologia aplicada ao varejo

**Ferramenta web publicada para criar placas e cartazes promocionais** com importação de produtos, personalização, pré-visualização e impressão. O objetivo é agilizar uma rotina real de supermercados e outros negócios do varejo.

`React` · `Vite` · `JavaScript` · `PDF / impressão`
